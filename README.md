# E-commerce

## Descripción del proyecto

Este proyecto consiste en el desarrollo de una página web de e-commerce, diseñada para ofrecer una experiencia de navegación sencilla e intuitiva. Su propósito es presentar productos de manera organizada y permitir a los usuarios explorar las distintas secciones del sitio.

La página está desarrollada utilizando HTML y CSS, aplicando estilos para lograr una interfaz visual atractiva y adaptable.

## Tecnologías utilizadas

* HTML5
* CSS3

## Ejecución del proyecto

Para visualizar la página, abrí el archivo `index.html` en un navegador web.
